照着设计稿做一张卡片，我改了三遍才对齐

2026 年 11 月 16 日 · 前端

任务很简单：照着设计稿，做一个 330×168 的卡片，圆角 18、内边距 26、有个浅色标签。看起来十分钟的事，做完对不上稿子，来回改了三遍。

坑一：宽度永远差一截

写了 width: 330px; padding: 26px;，量出来是 382px。

因为 CSS 默认的盒模型里，width 只算内容区，内边距和边框是**额外加在**外面的。解决办法就一行，写在样式表最前面：

*,
*::before,
*::after {
  box-sizing: border-box;
}

加上之后，width 就包含内边距和边框了，330 就是 330。这一行不加，后面所有对齐都会莫名差个几十像素。

坑二：三张卡片高度不齐

三张卡放一行，用 flex 排的。结果中间那张要求比两边高出 16px，怎么也高不出来——因为 flex 默认 align-items: stretch，会把所有子元素拉成一样高。

两种解法，我用了第一种：

  • 父容器加 align-items: flex-start，再给中间那张 transform: translateY(-16px)
  • 或者整行改用 grid，加 align-items: start
flex 的「拉伸」特性对卡片列表很方便，对「有高有低」的设计就是灾难。先想清楚要哪种。

坑三：hover 的时候整页在抖

最初是这么写 hover 的：

.card:hover {
  margin-top: -4px;
}

鼠标一进去，下面的元素跟着往上跳，整页在抖。因为改 margin 会触发重新排版。

改成位移就没这问题了：

.card {
  transition: transform .2s, box-shadow .2s;
}
.card:hover {
  transform: translateY(-3px);
  box-shadow: 0 10px 30px rgba(122, 88, 62, .10);
}

transform 不改变文档流，只改变绘制位置，所以又快又不会带崩邻居。

真正学到的三件事

  1. box-sizing: border-box 是地基，第一行就写。
  2. 间距统一交给 gap，别用 margin 一个个凑，也别用 <br>。
  3. 所有位移、缩放都用 transform，再配 transition 0.2s，观感立刻上一个台阶。

还有个小细节：日期这种小标签，加 letter-spacing: 2px 会显得很规整；中文标题加 -0.5px 反而更紧致。这类一两个像素的事，决定了「像稿子」还是「像练习」。
